## Восстановление в пустое аналогичное окружение

1. Разверните проект с той же конфигурацией и поднимите PostgreSQL и SeaweedFS:

   ```powershell
   docker compose up -d postgres seaweedfs
   docker compose run --rm backend alembic upgrade head
   ```

2. Скопируйте дамп в контейнер PostgreSQL и загрузите данные. Параметр `--disable-triggers` обязателен: в справочниках есть циклические внешние ключи.

   ```powershell
   docker cp .\backups\budgetbasket_data_20260727_151312.dump bb-postgres:/tmp/
   docker compose exec postgres pg_restore -U budgetbasket -d budgetbasket --data-only --disable-triggers --no-owner --no-privileges /tmp/budgetbasket_data_20260727_151312.dump
   ```

3. Остановите SeaweedFS и разверните архив в его пустой volume.

   ```powershell
   docker compose stop seaweedfs
   docker run --rm --volumes-from bb-seaweedfs -v ${PWD}\backups:/backup:ro alpine tar -xzf /backup/budgetbasket_seaweedfs_20260727_151312.tar.gz -C /
   docker compose start seaweedfs
   ```

4. Запустите остальные сервисы:

   ```powershell
   docker compose up -d backend frontend pgadmin file_guard
   ```

Контейнерные имена в командах соответствуют текущему `.env`: `bb-postgres` и `bb-seaweedfs`.
